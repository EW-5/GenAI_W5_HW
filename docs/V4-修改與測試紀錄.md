# My Dream Space｜V4 修改與測試紀錄

日期：2026-10-14。最終網頁執行只依賴 index.html 與固定版本 Three.js CDN，沒有後端、API Key、npm build 或外部模型／貼圖。這次完成的是 V4 本機版本；尚未發布 GitHub Pages。

## 本次擴充

家具從 34 增加至 58 種。衛浴 12 種：馬桶、洗手台、淋浴間、浴室收納櫃、浴缸、浴室鏡、毛巾架、浴室地墊、洗衣籃、洗衣機、衛生紙架、洗手乳。

廚房 8 種：工作台、水槽、瓦斯爐櫃、抽油煙機、雙門冰箱、中島、微波爐、電熱水壺。其他新增花瓶、壁鐘、抱枕、編織籃、鞋架、衣帽架、壁掛層板、書籍擺飾。價格為設計模擬用途。

淋浴間從簡化的兩面玻璃，改為四邊框架、玻璃側板及前方玻璃門，加入把手、頂噴出水孔、手持蓮蓬頭、軟管、混水控制與排水口。原版缺少這些細節，已補足；玻璃門目前不提供開合動畫。

租屋套房包含主房、浴室、廚房。自己的房子包含客廳、臥室、書房、浴室、廚房，預設五個空間同時呈現，排列在連接走道兩側。低牆、門洞、開門弧線、房間名稱及尺寸標示，形成整層居家圖；可切換成單獨房間檢視。舊作品保留既有家具與顏色，補上廚房。

新建時可設定主房寬深；編輯器可調整每間房的寬、深、高。寬／深範圍 2–12 m，高 2.4–4 m，編輯套用以 0.1 m 計。縮小時家具會移回新邊界；若家具在目前角度無法放入，拒絕變更並提示。尺寸調整可以復原／重做，納入 JSON 與本機保存。

新增 10 cm 拖曳吸附、正上方正交視角、專注設計模式及整個作品庫備份。V2／V3 JSON 可升級為 schemaVersion 4。

## 本機試用

預覽位址：http://127.0.0.1:8765/ 。重新整理載入最新版。自己的房子開啟時先顯示整層俯視，可選「自由視角」看立體圖。

1. 頂部選「整層住宅／單獨房間」與編輯房間。
2. 右側「空間尺寸」輸入寬深高，再按「套用尺寸」。
3. 左側分類選「衛浴」「廚房」或「裝飾」，新增物件。
4. 正交俯視適合配置；右上角可關閉 10 cm 吸附。
5. 「專注設計」放大 Canvas；「顯示面板」恢復側欄。
6. 整層模式下 PNG 輸出全屋；單獨房間模式輸出當前房間。

伺服器停止後，在 index.html 所在資料夾執行 `python -m http.server 8765 --bind 127.0.0.1`（需已有 Python）。

## 實際限制及 V5 候選

- 整層布局採固定兩排房間與連接走道。改尺寸會重新計算輪廓；寬深不同時剩餘區域屬共同空間。尚不能任意搬動房間或自由畫牆。
- 整層自由／俯視用低牆表現配置；室內視角恢復目前房間的牆高。完整門窗定位與建築漫遊尚未提供。
- 小物使用固定桌面高度，尚未自動尋找桌面、浴缸邊或沙發表面。家具不能任意堆疊。
- 玻璃門無開合動畫，水流、管線、排水、電線與門前走道淨寬沒有物理模擬。
- 保守包圍盒可能提醒桌椅重疊；浴室地墊等低矮裝飾排除碰撞提醒。
- 本機保存仍以瀏覽器與網址分隔，未提供多分頁同時編輯衝突合併。
- 大量家具、不同顯示卡、真實 CDN 斷線、手機及公開 HTTPS 網址仍需後續驗收。

建議 V5 先依你的試用決定：自由調整房間布局／門窗、物品吸附桌面與沙發、門前動線提醒。這些仍是候選需求，沒有擅自開始 V5。
