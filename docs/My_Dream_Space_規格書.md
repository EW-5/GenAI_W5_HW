# My Dream Space｜3D 理想空間設計模擬器
版本：V1.0｜日期：2026-10-14

## 1. 專案定位與目標
本專案是一個寫實風格、以電腦操作為主的互動式 3D 室內設計 Web App。使用者可選擇學生宿舍、租屋套房、家中臥室或自己的房子，配置家具、調整裝潢、管理預算，保存多個獨立作品，並輸出 JSON 設計檔與 PNG 圖片。核心理念是在不同空間及預算條件下自由探索理想居住方式。

作業要求：最終僅交付一個 index.html（CSS、JavaScript 內嵌），可在瀏覽器實際操作並部署 GitHub Pages；不使用後端、帳號、資料庫或 API 金鑰。允許從固定版本 CDN 載入 Three.js，但不能依賴額外的自有模型、貼圖或程式檔。需網路才能載入 CDN。

## 2. 範圍與非目標
包含：4 種居住場景、3D 空間、約 30 種家具、選取／新增／拖曳／旋轉／複製／刪除、碰撞警告、三種視角、牆面／地板／燈光／主題、預算、多專案、復原重做、本機保存、JSON 匯入匯出、PNG 匯出、首次教學。
不包含：登入、雲端同步、多人協作、真實商品結帳、自由建牆、完整建築漫遊、照片級渲染、AI 自動設計。

## 3. 使用流程
首頁 → 新建專案／作品庫 → 選擇場景 → 命名與設定預算 → 載入預設格局和附贈家具 → 3D 編輯與裝潢 → 自動保存 → JSON 備份／PNG 輸出。作品庫可開啟、重新命名、複製、刪除專案（刪除需確認）。

## 4. 場景定義
所有尺寸以公尺為單位，Y 軸為高度；房間固定格局與門窗，無法拆牆。預設初始家具可移動或刪除且不計價。
- 學生宿舍：3 × 4 × 2.8 m；單人床、書桌、椅子、衣櫃。
- 租屋套房：4 × 5 × 2.8 m；雙人床、書桌、椅子、衣櫃。
- 家中臥室：4 × 4 × 2.8 m；床、衣櫃、床頭櫃。
- 自己的房子：由三個獨立可切換的房間構成，不要求三間拼成同一建築；客廳 6 × 5 × 3 m（沙發、茶几、電視櫃）；臥室 4 × 5 × 2.8 m（雙人床、衣櫃、床頭櫃）；書房 4 × 3.5 × 2.8 m（書桌、辦公椅、書櫃）。各房間家具及裝潢獨立，整個專案共用預算。

## 6. 3D 編輯與控制
- 左鍵點選家具：高亮外框，右側顯示屬性；左鍵拖曳選中家具：在合法平面上移動；右鍵拖曳：環繞鏡頭；滾輪：縮放。
- 支援旋轉按鈕（例如 ±15°）與角度數值控制、複製、刪除（Delete）、取消選取（Esc）、復原（Ctrl+Z）、重做（Ctrl+Y）。輸入欄聚焦時快捷鍵不應干擾文字。
- 物件拖曳時禁止同時觸發鏡頭旋轉；每次完整拖曳只寫入一筆歷史；最多保留 50 筆復原狀態；切換專案可清空歷史。
- 地板家具限制在房間邊界內，且落在地板高度；掛畫、窗簾、吊燈等使用適當牆面／天花板錨點；桌燈、螢幕可用合理的桌面預設高度或專用定位，不要求完整任意堆疊。
- 家具之間可重疊，但應以紅色外框／文字警告；採簡化水平包圍盒（旋轉後更新範圍），不需要物理引擎。房間外邊界不可超出。
- 自由視角：環繞觀看；俯視：自上而下布置；室內視角：接近人眼高度，限制鏡頭位置以減少穿牆；可切換回自由視角。自由與俯視視角可隱藏遮擋前牆。

## 7. 裝潢系統
- 牆壁：白、米、灰、奶茶、淺綠與自訂顏色。
- 地板：淺木、深木、磁磚、石紋、水泥；用材質參數或程序化紋理，不依賴外部貼圖。
- 燈光：白天、傍晚、夜晚，亮度調整；燈具可以有發光材質，不強制每盞燈產生即時陰影。
- 主題：現代、北歐、日系、工業、極簡；只套用牆面、地板、環境燈光預設，不移動、刪除或重新上色既有家具。

## 8. 預算規則
每個專案設定一筆可修改預算；多房間專案跨房間合計。總花費 = 所有房間中 isStarter=false 的家具價格加總；剩餘 = 預算 − 總花費。附贈家具不計價；複製附贈家具產生新購買物件，須計價；刪除新購物件即從方案成本扣除；超支顯示紅色警告及超額，但仍可新增。所有顯示數字應由當前家具資料重新計算，不要儲存不一致的快取總額。

## 9. 多專案與保存
每個專案具 id、name、sceneType、budget、createdAt、updatedAt、rooms；每房間具 id、size、decor、furniture[]。可建立、開啟、改名、複製、刪除多個獨立專案。使用 localStorage 儲存輕量 JSON；拖曳結束與編輯完成後 debounce 自動保存，切換房間或專案前保存。不要將大型 Canvas 圖片或 3D 幾何資料放入 localStorage。保存失敗要顯示錯誤與 JSON 備份提示。
JSON 匯出需含 schemaVersion，匯入須驗證必要欄位、資料類型、房間及家具 typeId，非法檔案不得覆蓋原專案；預設匯入為新專案，重新配置唯一 ID。
PNG 匯出當前 3D 房間視角，隱藏選取框、碰撞警告及 UI；輸出失敗顯示提示；多房間逐間匯出。

## 10. UI/UX
- 首頁：品牌、簡介、新建、作品庫。
- 新建流程：選擇四種場景、命名、設定預算。
- 作品庫：卡片顯示名稱、場景、更新時間；開啟／改名／複製／刪除。
- 編輯器：頂部專案與房間切換、復原重做、儲存、匯出；左側家具分類／搜尋／價格；中央大面積 3D Canvas；右側選取家具屬性、裝潢及預算；底部狀態提示。
- 現代寫實室內設計工具風格：米白、暖灰、木色、清楚排版與操作回饋；桌機優先，手機至少能查看首頁與作品庫。
- 首次進入顯示可關閉的新手教學，並提供再次開啟入口。

## 11. 技術與效能
使用 HTML5、內嵌 CSS、原生 JavaScript、固定版本 CDN Three.js、WebGL、localStorage、Blob/File API。可用單一 type="module" 腳本並從 CDN 匯入 Three.js；不得使用必須打包或 Node 伺服器才能運作的方案。GitHub Pages 路徑相容、HTTPS 安全。3D 物件刪除及場景切換應妥善清理資源；控制陰影與幾何複雜度；Canvas resize 正常；WebGL/CDN 失敗有錯誤訊息。寫實程度以程序化家具細節、材質與光影為主，兼顧流暢度，不承諾照片級品質。

## 12. 例外與驗收
- 房間外拖曳：阻擋或夾限到合法位置；家具重疊：警告但允許；預算超支：警告但允許。
- 刪除專案與重設房間：二次確認；無選取時清空屬性面板；復原堆疊空時停用按鈕。
- JSON 格式錯誤、localStorage 滿、WebGL 不支援、CDN 失敗、PNG 匯出失敗：清楚提示且不破壞現有設計。
- 驗收 T01–T22：公開網址可開；四場景可建立；房間牆地板可見；30 種家具可新增；家具拖曳、旋轉、複製、刪除正常；重疊警告；三視角；裝潢與主題；跨房間預算正確；多專案隔離；復原重做；重新整理可恢復；JSON 匯入匯出；PNG 匯出；新手教學；異常不崩潰；最終只有 index.html。
