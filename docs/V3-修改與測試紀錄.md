# My Dream Space｜V3 修改與測試紀錄

日期：2026-10-14。成品仍為單一 index.html，CSS、JavaScript 與程序化材質全部內嵌，固定使用 CDN Three.js 0.160.1。本輪沒有發布、push 或建立遠端儲存庫。

## 需求變更

- 租屋套房保留 4 × 5 m 主房，另加 2 × 2.5 × 2.8 m 獨立浴室。
- 自己的房子保留客廳、臥室、書房，另加 2.5 × 3 × 2.8 m 獨立浴室。
- 由頂部房間選單切換，共用專案預算。浴室面積額外增加，不扣除原主房面積，也不拼成同一建築。
- 增加模擬價格：馬桶 NT$ 6,500、洗手台 NT$ 4,500、淋浴間 NT$ 8,000、浴室收納櫃 NT$ 2,800，共 34 種家具。
- 浴室預設馬桶、洗手台、淋浴間免費，複製後計價。舊 V2 作品与 JSON 備份自動補上浴室，保留原房間資料。

## 修改前問題 → 解法 → 測試方法 → 結果

| 原問題 | 解法 | 測試 | 結果 |
|---|---|---|---|
| 缺少浴室 | 獨立浴室、程序化衛浴家具、高窗與側門 | 開啟舊作品、新建房子與切換浴室 | 通過；套房 2 房間、房子 4 房間 |
| 重疊沒有提醒 | 旋轉後水平包圍盒、紅框與文字 | 複製浴室櫃 | 通過；提醒 1 組重疊但仍可操作 |
| 無法回退 | 全專案歷史、50 步上限、拖曳只記一筆 | 新增、複製、拖曳、重設後復原與重做 | 通過；Ctrl+Z／Ctrl+Y 可用 |
| 只有自由視角 | 自由／俯視／室內視角、遮擋牆隱藏 | 三模式切換與俯視拖曳 | 通過；室內採受限制的人眼視角 |
| 缺少可攜備份 | schemaVersion JSON 匯出、嚴格驗證後匯入、新 ID | 實際下載並以檔案選擇器重新匯入 | 通過；另建作品，浴室花費 NT$ 2,800 恢復 |
| 非法檔案可能破壞作品 | 整份驗證後才寫入 | 瀏覽器匯入非法 JSON | 通過；作品數仍為 7，顯示失敗原因 |
| 缺少圖片輸出 | Canvas PNG，隱藏選取與碰撞框 | 實際下載並檢視含重疊家具的輸出 | 通過；沒有 UI 或紅框 |
| 缺少新手引導 | 首次教學、關閉與重新開啟入口 | 新作品首次開啟教學 | 通過首次顯示與關閉 |
| 確認視窗待驗證 | 頁面內對話框，重設可復原 | 取消重設、確認重設、復原 | 通過；專案永久刪除未實際執行 |
| 保存與輸出例外 | 救援備份、損壞資料保護、PNG 空值／渲染失敗／逾時處理 | 隔離 Node VM 模擬錯誤 | 通過模擬測試；不代表所有硬體故障已實測 |

瀏覽器數值實測：新增浴室櫃 2,800 → 複製 5,600 → 復原 2,800 → 重做 5,600。一次拖曳可一次復原。重設測試：花費 8,400 → 重設 0 → 復原 8,400。

JavaScript 語法檢查通過。資料測試通過：JSON ID 隔離、11 種非法匯入、V2 升級、50 步歷史上限、復原後新操作清除重做分支、碰撞排除項目、儲存 quota／損壞資料保護、PNG 空值與渲染失敗恢復。瀏覽器測試沒有記錄到 JavaScript 警告或錯誤。

第一次 PNG 下載事件測試逾時，改以獨立背景測試頁後實際下載成功並檢查圖片，未把逾時當成成功。

## 如何試用

本機預覽：http://127.0.0.1:8765/ 。伺服器運行時可直接開啟，重新整理載入最新版。

1. 新建空間：選場景、名称與預算。
2. 頂部房間選單切換浴室，左側分類選「衛浴」。
3. 畫面右上角選自由、俯視或室內視角。
4. 頂部「JSON 備份」下載整個專案；作品庫「匯入 JSON」另建作品。
5. 「匯出 PNG」只輸出當前房間，其他房間需切換後逐間匯出。

伺服器停止後，可在含 index.html 的資料夾執行 `python -m http.server 8765 --bind 127.0.0.1`（需已有 Python），再開啟上述網址。直接雙擊 HTML 未在本輪作為驗收方式。

## 已知限制與後續建議

- 浴室為獨立切換房間，沒有管線、排水或門扇動線模擬。
- 室內視角有邊界限制，是環繞／縮放模式，非 WASD 完整漫遊。
- 碰撞使用保守水平包圍盒，椅子收進桌下也可能提醒。地毯、牆面、桌面與天花板物件排除檢查。
- 掛畫／窗簾固定後牆；桌燈／螢幕固定 0.78 m 高度，未自動吸附桌面。
- 本機作品依瀏覽器與網址分隔；未設計多分頁同時編輯的衝突合併。
- CDN／WebGL／context loss 提示已實作，未用真實斷網或不支援 WebGL 的裝置完整驗證。
- V4 材質精修、效能／多裝置驗收與 GitHub Pages 公開部署尚未完成。

建議優先加入公尺刻度、格線吸附與走道距離；再考慮廚房區、家具清單與成本明細。這些仍是後續建議，未實作。
